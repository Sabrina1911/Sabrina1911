**Featured Project — GreenInference (formerly CarbonLensAI)**

GreenInference is an AI-driven prompt optimization and efficiency analysis system inspired by the principles of Green AI — focusing on reducing computational cost while preserving output quality.

It is built as a modular Python pipeline with a Streamlit-based interactive interface for evaluating and optimizing large language model (LLM) prompts.

*What it does*

* Optimizes LLM instruction prompts using a T5-based rewriter model
* Preserves protected content (e.g., transcripts, structured payloads) without modification
* Applies semantic safety checks using embedding similarity
Compares:
- Rule-based optimization
- Learned (model-based) optimization
Measures:
- Token reduction
- Efficiency gains
- Output consistency
*Why it matters**

* Promotes responsible AI usage (not blind optimization)
* Connects model efficiency → energy consumption → sustainability
* Designed for:
- auditability
- reproducibility
- academic evaluation

This project reflects my interest in building efficiency-aware AI systems that balance performance, safety, and real-world constraints.

**Key Project — INSIGHT 311**

Streamlining Municipal Service Requests using AI

INSIGHT-311 is an AI-powered municipal service assistant designed to improve how citizens report and track city issues such as potholes, graffiti, and waste management.

It combines voice interaction, natural language understanding, and intelligent workflows to reduce manual effort and improve response efficiency.

*Use Case 1: AI Voice Intake (Sentiment + Classification)*

Focus: Automated intake & emotional intelligence
* Converts speech to structured tickets in real-time
* Performs:
- Automatic category classification
- Multimodal sentiment analysis
- Named Entity Recognition (NER)
* Reduces dependency on human operators during high call volumes

*Use Case 2: Duplicate Detection & Ticket Linking*

Focus: Operational efficiency & data integrity
* Identifies repeated reports of the same issue
* Uses:
- Spatial + category matching
- Confidence-based linking
* Prevents redundant work (e.g., multiple crews for one issue)
* Provides a unified dashboard view for operators

*Use Case 3: Smart Status Tracking (RAG)*

Focus: Transparency & citizen communication
* Uses Retrieval-Augmented Generation (RAG)
* Automatically updates citizens with ticket progress
* Features:
- Status-triggered notifications
- Intelligent message generation
- Automated delivery

Impact
- Faster issue reporting
- Reduced operational overhead
- Improved citizen experience
- Scalable for real-world municipal systems
